# **App Name**: SubscriBoost

## Core Features:

- Subscription Dashboard: Display an overview of all digital subscriptions as interactive cards, showing service name, monthly cost, and next billing date.
- Total Monthly Spend Display: Automatically calculate and prominently display the aggregate monthly expenditure across all active subscriptions.
- Subscription Management: Functionality to add new subscriptions with details (name, cost, currency, billing cycle) and to edit or delete existing entries.
- Internationalization System: Implement a complete system for displaying all texts and currency formats in both English and Spanish, switchable by the user.
- Dynamic Theme Toggle: A functional and readily accessible button to switch between the predefined light and dark UI themes.

## Style Guidelines:

- Light Theme Background: A clean, soft grey base (#F8F9FA) to provide a spacious feel. Container backgrounds will be pure white (#FFFFFF).
- Light Theme Primary Accent: A vibrant 'teal verdoso' (#20C997) for primary actions, indicators, and key informational highlights.
- Light Theme Text Color: A dark, almost black hue (#212529) ensuring maximum readability and contrast.
- Dark Theme Background: A deep, muted dark grey (#212529) to provide a sophisticated and eye-friendly base. Container backgrounds will be a slightly lighter dark grey (#343A40).
- Dark Theme Primary Accent: A luminous 'teal verdoso' (#38D39F), maintaining the brand hue while ensuring visibility and vibrancy in the dark scheme.
- Dark Theme Text Color: A very light, near-white hue (#F8F9FA) for optimal legibility against dark backgrounds.
- Headline and body font: 'Inter' (sans-serif). Chosen for its modern, highly legible, and neutral aesthetic, suitable for both display and extended reading in a management application.
- Utilize a consistent set of minimal, clean outline icons for actions (e.g., add, edit, delete, settings) and category representations, promoting a streamlined visual language.
- A responsive dashboard layout featuring subscription cards arranged in an intuitive grid for easy scanning. A prominent section at the top will clearly display the aggregated total monthly spend.
- Subtle and swift animations for theme transitions, card interactions (e.g., hover effects or detailed view expansion), and form submissions, providing fluid user feedback without distraction.
